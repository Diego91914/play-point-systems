# How Close Are We?

A family table game where everyone answers the same 1–100 prompt privately. The fun is not finding an objective truth; it is discovering how similarly the table thinks.

## MVP loop

1. A signed-in host creates a room.
2. Guests join by room code or shared link with only a first name.
3. The host starts a 7-round game.
4. Each round shows one family-safe prompt and every player secretly chooses a number from 1 to 100.
5. When everyone has answered, all answers reveal together.
6. Each player scores based on distance from the table average. Exact/near matches earn the most points.
7. After seven prompts, highest total wins.

## Scoring

- Exact match with rounded table average: 5 points
- Within 5: 4 points
- Within 10: 3 points
- Within 20: 2 points
- Otherwise: 1 point for participating

A unanimous answer earns every player a 2-point Same Brain bonus.

## Product intent

Prompts should create conversation, not test knowledge. Example: “How embarrassing is it when restaurant staff sing Happy Birthday to you?” The phones collect private opinions, then get out of the way for the reveal and discussion.
