# Inside Man expansion hooks

Potential post-MVP additions that fit the current engine direction:

- themed scenario packs
- scenarios where no Inside Man exists
- two-Inside-Man mode for larger rooms
- special Crew roles with asymmetric information
- Ghost-style powers if elimination is ever introduced
- final-betrayal prediction mechanic
- host-selectable match length
- difficulty tiers and mature/family filters
- authored scenario catalog stored in database rather than source

These are intentionally not part of the first playable release; the MVP focuses on the core social loop and keeping every player active.
