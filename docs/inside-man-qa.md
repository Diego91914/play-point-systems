# Inside Man QA targets

Before production release verify:

1. signed-in host can create a room;
2. unsigned guest can open a QR/code join URL;
3. four players can start and exactly one sees Inside Man;
4. private objectives do not leak between clients;
5. mission resolves only after all players vote;
6. accusation can be spent only once per player;
7. wrong conviction adds sabotage progress;
8. correct conviction ends the match for Crew;
9. first side to three mission points ends the match;
10. replay returns everyone to the lobby with fresh roles and missions.
